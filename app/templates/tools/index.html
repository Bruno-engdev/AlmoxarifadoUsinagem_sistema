Exportar Estoque de Ferramentas

A exportação seguirá os filtros atuais da tela. Selecione as colunas que deseja incluir na planilha.

Selecione ao menos uma coluna.

Gera uma página de etiquetas para impressão em folha A4 (4 colunas × 13 linhas por folha). Os filtros atuais do browse serão respeitados. Cada etiqueta contém a Localização, o ID TOTVS e o Nome da Ferramenta. Utiliza quantas folhas forem necessárias.

Após abrir a página, use Ctrl + P para imprimir.

Abrir Página de Impressão

Gera uma folha A4 com formulário de movimentação manual para uso quando o sistema estiver offline. O formulário traz campos para retirada, devolução e reposição, além de espaço para registrar várias ferramentas na mesma folha.

Após abrir a página, use Ctrl + P para imprimir e deixe folhas em branco disponíveis no almoxarifado.

Abrir Formulário

Gera uma folha A4 para controle manual de empréstimos, com campos para retirada e devolução da ferramenta. A tabela traz data e hora de cada etapa, além de assinatura do funcionário na retirada e na devolução.

Após abrir a página, use Ctrl + P para imprimir e manter folhas prontas para uso manual.
